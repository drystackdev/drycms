Kết nối MCP tới drycms

Cho Claude Desktop hoặc Claude Code đọc và ghi nội dung của bạn trực tiếp, bằng đúng quyền hạn tài khoản của bạn — không có cơ chế quyền riêng cho MCP.

Phase 1+2+3 · đã triển khai 6 tools Xác thực bằng Personal Access Token

1. Tạo token trong Profile

1

Token thay bạn đăng nhập — MCP client không phải trình duyệt nên không có cookie phiên, phải xác thực bằng token này thay thế.

My profile→mục "API Token"→nhập nhãn (vd Claude Desktop)→Generate

Token chỉ hiện ra đúng một lần ngay sau khi tạo — bấm nút copy rồi lưu lại an toàn (trình quản lý mật khẩu, biến môi trường...). Đóng hộp thoại rồi thì không lấy lại được nữa, phải Generate token mới nếu quên.

2

Mỗi token có dạng mcp_<chuỗi ngẫu nhiên>, đại diện đúng cho tài khoản đã tạo ra nó — quyền hạn của token luôn bằng đúng quyền hạn (role/permissions) hiện tại của bạn, tra lại mới mỗi lần gọi, không đóng băng lúc tạo.

2. Trỏ MCP client vào drycms

3

Claude Code (CLI)

Cách nhanh nhất — 1 lệnh, thêm server dạng HTTP kèm header xác thực:

terminal
# thay URL + token bằng của bạn
claude mcp add --transport http drycms \
  https://your-domain.example.com/dry/api/mcp \
  --header "Authorization: Bearer mcp_xxxxxxxx"
ℹ️ /dry là base path mặc định của drycms (DryOption.path). Nếu instance của bạn đổi sang path khác, sửa lại URL cho khớp.
4

Claude Desktop

Settings → Connectors → Add custom connector → dán URL .../dry/api/mcp, thêm header Authorization: Bearer <token> ở mục header tuỳ chỉnh (nếu bản Desktop đang dùng có mục này — vị trí chính xác đổi theo từng phiên bản app).

⚠️ Đã verify giao thức (JSON-RPC/tool-call) đúng end-to-end bằng curl thật trên dev server, nhưng chưa cắm thử bằng chính app Claude Desktop. Nếu giao diện Settings khác mô tả trên, ưu tiên cách CLI (Claude Code) ở bước 3, đã đúng theo cú pháp claude mcp add --transport http hiện hành.

3. Kiểm tra kết nối

5

Hỏi thẳng trợ lý AI trong client vừa kết nối:

thử trong Claude
"Liệt kê content type của drycms giúp mình"

Trả lời đúng danh sách content type nghĩa là token + kết nối ổn. Gặp lỗi 401: token sai/đã bị revoke, hoặc URL/base path chưa đúng.

6

Xem lại AI vừa làm gì bất cứ lúc nào ở My profile → AI Activity (MCP) — danh sách 50 tool call gần nhất, tự làm mới mỗi 5 giây (không phải theo thời gian thực từng mili giây, chỉ poll định kỳ).

Các tool đang có

Mỗi tool tra lại đúng quyền hạn thật của bạn trên content type liên quan (giống hệt cách Magic Chat trong admin đã kiểm tra) — không có allow-list riêng cho MCP.

list_content_types Liệt kê toàn bộ content type (collection/singleton) hiện có.
list_entries Liệt kê entry trong 1 collection, có thể lọc theo từ khoá. quyền view
get_entry Lấy 1 entry theo id, hoặc entry của 1 singleton. quyền view
list_media Liệt kê file/folder trong thư viện media.
create_entry Tạo entry mới trong 1 collection. quyền magic + create
update_entry_fields Ghi đè field trên entry có sẵn hoặc 1 singleton. quyền magic + update
ℹ️ create_entry/update_entry_fields chỉ nhận field vô hướng (text/richtext/number/boolean/date/select) — field relation và image chưa hỗ trợ qua MCP, phải set tay trong admin UI sau đó.

Lưu ý bảo mật

  • Token = chìa khoá vào đúng tài khoản của bạn. Ai cầm được token đều thao tác được như chính bạn đang đăng nhập.
  • Thu hồi bất cứ lúc nào ở My profile → API Token → Revoke — có hiệu lực ngay cho mọi client đang dùng token đó.
  • Content type nào bị khoá Magic (role/user/aiKey/menu/redirect/các singleton hệ thống) thì MCP cũng không đọc/ghi được, giống hệt Magic Chat trong admin.
